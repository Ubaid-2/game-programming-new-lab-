# Park Physics

Unity physics simulation environment demonstrating rigidbodies, bouncy physics materials, collision detection, and procedural scene generation.

## Features

- **Physics Materials**: Configured `BouncyBall` physics material with maximum bounce combine.
- **Dynamic Rigidbodies**: Bouncing spheres falling under gravity and interacting with park objects.
- **Environment Objects**: Custom park elements including ground plane, benches, trees, barrels, and pathways.
- **Resetter Scripts**: Scripting to handle sphere repositioning and continuous physics tests.
